1Arrays — a list of things

An array holds a list of values in order. You get one item out with square brackets and a position (starting at 0).

const fruits = ["apple", "pear", "plum"];
fruits[0]; // "apple"
fruits.length; // 3

2Objects — a bundle of named values

An object holds named properties. You get one out with a dot and the name.

const person = { name: "Sam", age: 34 };
person.name; // "Sam"
person.age;  // 34

An array of objects — like the ledger you're working with — combines both: a list, where each item has named fields.

const orders = [
  { item: "desk", price: 120 },
  { item: "lamp", price: 25 }
];
orders[0].item;  // "desk"
orders[1].price; // 25

3Looping through an array

orders.length tells you how many items there are, so the loop always covers exactly the right number regardless of how big the list is.

for (let i = 0; i < orders.length; i++) {
  console.log(orders[i].item);
}

4The accumulator pattern

To build up a total (or a count) across a loop, start a variable before the loop, then add to it inside.

let total = 0;
for (let i = 0; i < orders.length; i++) {
  total += orders[i].price;
}
// total is now 145

total += x

Shorthand for total = total + x. Same idea works for counting: count++ is shorthand for count = count + 1.

Common mistake: declaring let total = 0 inside the loop — it resets to 0 every time round, so you only ever get the last item's value.

5Filtering inside a loop

Combine the accumulator with an if to only add matching items.

let total = 0;
for (let i = 0; i < orders.length; i++) {
  if (orders[i].item === "desk") {
    total += orders[i].price;
  }
}

Check yourself

1. Why does let total = 0 need to sit outside (before) the loop, not inside it?

If it's declared inside, every iteration wipes it back to 0 before adding — you'd only ever end up with the last item's value, not a real running total.

2. What does orders[1].price actually mean?

Arrays count from 0, so index 1 is actually the second item — orders[0] is the first.

3. Inside a loop, what does if (purchases[i].type === "food") do?

The if condition gates what's inside it — only rows matching "food" exactly get counted, everything else is skipped without being changed.
