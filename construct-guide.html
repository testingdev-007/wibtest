1Calling a function

A function does something when you call it — write its name, followed by brackets, followed by a semicolon.

sayHello();
Common mistake: forgetting the brackets (sayHello;) or the semicolon. Both matter.

2Sequencing — code runs top to bottom

Each line runs in order, one after another. If you call the same function three times, it runs three times, in that order.

stepForward();
stepForward();
turnAround();

3Loops — repeating without repeating yourself

A for loop repeats a block of code a set number of times. This runs stepForward() exactly 6 times:

// i starts at 0, runs while i is less than 6, adds 1 each time
for (let i = 0; i < 6; i++) {
  stepForward();
}

Reading the loop

PartMeaning
let i = 0start counting at 0
i < 6keep going while this is true
i++add 1 to i after each run

The number in the middle is how many times it repeats. Change 6 to change the count.

Common mistake: the loop count doesn't have to match the number of moves you'd guess by eye — count carefully, or you'll stop one short (or one too far).

Check yourself

1. What's wrong with moveForward on its own, with no brackets?

Brackets are what actually trigger a function. Without them, you're just referring to it by name, not running it.

2. In for (let i = 0; i < 4; i++), how many times does the loop body run?

i counts 0, 1, 2, 3 — four values, all less than 4 — so the body runs 4 times.

3. Does calling turnRight(); move the rover to a new cell?

Turning and moving are separate — you need a moveForward() after turning to actually go anywhere in the new direction.
