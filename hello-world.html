Step 1 of 4

What actually is a "console"?

You're going to see the word "console" a lot today. Here's all it means:

A console is just a simple box where you type an instruction, press a button, and the computer replies straight away. That's genuinely it. No menus, no clicking around — just type something, and something happens.

Below is exactly what one looks like. It's dark, it uses a typewriter-style font, and it's where you'll type your first ever instruction.

  console
// this is what an empty console looks like — nothing has happened yet
Step 2 of 4

Your turn — type your first instruction

Every programming language has a way to display a message. In JavaScript — the language you'll see today — it looks like this:

  console
// type the instruction below into the box, then click Run

Type exactly this, including the punctuation:

console.log("Hello, World!")
👆 Click inside the box above, type the instruction, then click the blue Run button
Step 3 of 4

One more time — with your own name

You just did the exact thing every developer does dozens of times a day: tell the computer to display something, and watch it happen immediately. Let's do it once more, this time with your own name instead.

  console
// replace YOUR NAME below with your actual name, keeping the quote marks

Type this, swapping in your own name:

console.log("Hello, YOUR NAME!")
Step 4 of 4 · You're done!

🎉 That's your first line of code, ever

Genuinely — that's not a simplified taste of coding, that's the real thing. Every developer, on every project, starts exactly like this.

  • A console is just a box where you type an instruction and see the result immediately.
  • console.log(...) is the instruction for "display this on screen."
  • Anything you want to display as text goes inside quote marks "like this".
💼 Where this shows up in real jobs: every single professional developer uses a console every day — to check their code is doing what they expect, to try out an idea quickly, or to fix something that's gone wrong. It's less a "coding trick" and more like a mechanic's basic toolkit — you never stop using it.
